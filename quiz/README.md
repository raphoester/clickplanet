# The quiz bank

`bank.json` is every question the game can ask and the answer to each. It follows
[`/proto`](../proto) and [`/map`](../map): the root holds the source, one command writes it, and the
app that needs it carries a **committed, byte-identical copy** generated by a target, because each
app's Docker build context is its own directory and neither can read the repo root at build time.

| app | copy | refreshed by |
| --- | --- | --- |
| backend | `apps/backend/generated/quiz/bank.json`, embedded | `make quiz` |
| frontend | **none, on purpose** | — |

```bash
cd apps/frontend && npm run quiz:generate   # rewrite /quiz/bank.json
cd apps/backend && make quiz                # → apps/backend/generated/quiz
```

**The name never changes**, unlike the map's blobs, which the browser caches by name. So git shows a
new bank as a change to the old one. A stale copy is caught by `make check-quiz` instead, which the
pre-push hook and the backend's CI run: the two files must be byte-identical.

**One question per line**, so a diff of the bank is one line per question that changed, and a
question removed is one line removed.

## The frontend never gets a copy

This is the one thing shared here that is **not** shared with both apps, and the reason is the whole
security model: the answer is in the file. A bank served to the page is a bank anyone can fetch with
the network tab open, and every quiz would be free.

So the bank is the server's. `OpenQuiz` hands the client one question and three choices, and
**which of the three is right never leaves the server**. `AnswerQuiz` is what compares, and
`OpenQuiz` is what starts the clock — see the backend's CLAUDE.md.

**Nothing about a question reaches the client before it is opened**, `subject` included. The banner
carried the subject country once, so it could fly a flag: that flag was the answer to 417 of these
1014 questions, every `capitalOf` and every `mostPeople`. `subject` is for the leaderboard lean and
for the broadcast after a win, and a template author does not have to think about it leaking,
because it never goes out before an answer.

## Two halves, and why they are separate

**The derived half is about 820 questions and cannot rot.** Capitals, land borders, continents and
populations, from the same pinned Natural Earth snapshot `map/` is cut from
(`NATURAL_EARTH_TAG` in `apps/frontend/scripts/map/naturalEarth.mjs`). It is regenerated, never
corrected: a wrong answer here is a generator to fix or a pin to move, not a line to edit.

Two of those templates are worth knowing about:

- **A border is a border on the map being played**, not one in a polygon file. `scripts/quiz/
  adjacency.mjs` reads the shipped coordinates and borders blobs and calls two countries neighbours
  when two of their tiles touch on the lattice — the same edge relation the flags and the backend's
  own adjacency are built from. So "which of these borders Estonia" can be answered by looking at
  the globe, and France borders Brazil, because on this map it does.
- **A population is the one derived fact that moves**, so `mostPeople` is only built where the
  answer wins by two times over. That ordering survives a decade of either country growing. Its
  wrong answers are the biggest countries under that line, not any smaller one: "France or San
  Marino" asks nothing.

Some questions are too easy to be worth a charge, and the derived half leaves them out by rule:

- **No capital or continent question about a country everybody knows.** "What is the capital of
  France?" is not a question. A country everybody knows is one whose capital Natural Earth marks as
  a world city (`worldcity`): about 40 of them, Paris, Tokyo and Cairo, but not Canberra, Ottawa or
  Brasília, which are good questions.
- **No answer that repeats a word of the question**: "Monaco is the capital of which country?",
  "Which continent is S.Africa in?". A border question picks another neighbour instead.
- **No "Seven seas (open ocean)"**, which is Natural Earth's continent for an island far out at sea,
  and no continent that only the question's own country is on (Antarctica), as answers or as
  wrong ones.

**The hand-written half is about 500 questions** in `apps/frontend/scripts/quiz/extra.json`, for what
no dataset here can answer — oceans and mountains, famous places and people, inventions, old names,
flags, history. It is a hand-kept list, and the rule at the top of that file is the important part:
**nothing that a newspaper could make wrong.** A fact that moves — who holds an office, which
religion or economy is biggest, what a currency is — is allowed only with its year in the question:
"who *was* president of Portugal in 2020", never "who *is*". Then the answer is history, and nothing
has to be revisited when the news changes.

A player reads the question and the three choices in eight seconds, so a question must not answer
itself: no answer that repeats a word of the question ("which river gives its name to Niger and
Nigeria"), no translation that anyone can read ("what does Costa Rica mean"), and no wrong answers
so absurd that the right one is the only choice left.

## Adding to it

- A new *kind* of question is a template in `apps/frontend/scripts/quiz/templates.mjs`. It must be
  derivable from the pinned data, and it must produce at least two wrong answers or it is skipped.
- A new *one-off* question is an entry in `extra.json`.
- Either way: `npm run quiz:generate`, then `make quiz`, then commit both copies.

The generator refuses to write a bank where a question has no id, a repeated id, fewer than two
wrong answers, or an answer that is also one of its own wrong ones — which is the fault a derived
bank produces quietly, when two countries share the name of a capital.

**`namesSubject` says whether the question names its subject country**, and only those are leaned
toward the countries leading the map. "Sofia is the capital of which country?" does not name
Bulgaria, because Bulgaria is the answer: if it leaned too, "press the leader" would answer it. The
generator works it out from the text, for the hand-written half too, so a template author does not
set it.

**Each question carries five wrong answers and a round shows two.** So the same question is not the
same three choices twice, and "press the second one for Estonia" is worth nothing.
